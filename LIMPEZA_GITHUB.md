# Publicação limpa no GitHub Pages

1. Abra o repositório no GitHub.
2. Apague os arquivos e pastas antigos da raiz publicada.
3. Envie **o conteúdo desta pasta**, mantendo `index.html` diretamente na raiz.
4. A estrutura final deve começar com:

```
index.html
README.md
VERSAO.txt
css/
js/
database/
docs/
sql/
```

5. Faça o commit.
6. Aguarde o GitHub Pages concluir a publicação.
7. Abra o site e pressione `Ctrl + F5` uma vez.

O arquivo `js/config.js` já contém a Project URL e a Publishable Key informadas. Não use Secret Key no frontend.
