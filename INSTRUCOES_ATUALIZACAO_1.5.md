# Frontend 1.5

Publique somente depois de atualizar o banco e a API 3.3.

Pode subir por cima da versão atual. O runtime é `js/runtime-v15/`.

Depois do deploy:
1. Ctrl + F5.
2. Confirme `build 1.5`.
3. Teste cadastro Fixo/Móvel.
4. Teste chips de centros permitidos.
5. Teste movimentação completa.
6. Teste abertura/conclusão de manutenção.
7. Confira badges e histórico.
