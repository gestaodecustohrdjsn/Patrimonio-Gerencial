# Frontend 1.4

## Ordem
1. Atualize primeiro o banco/API para a API 3.2.
2. Depois publique este frontend no GitHub Pages.
3. Pode subir por cima da versão atual: o runtime mudou para `js/runtime-v14/`.
4. Faça `Ctrl + F5` e confirme `build 1.4`.

## Principais mudanças
- `Invalid time value` tratado de forma segura.
- Patrimônios: filtros combináveis + ações por ícone.
- Ficha: modo edição por permissão.
- Manutenção funcional.
- Etiquetas: seleção livre, filtros, 1 item = PNG, vários = ZIP.
- Exclusão definitiva: apenas ADMIN e confirmação pela ID interna.
